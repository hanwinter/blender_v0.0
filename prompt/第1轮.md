请在当前目录创建一个新的 Web 3D 项目，项目目标是后续用于展示 Blender 模型，并支持模型部件 Hover、点击、高亮和信息展示。

本轮只完成 **V0 项目骨架 + Cube 交互验证**，不要接入人体模型，不要自行扩展复杂功能。

# 五、当前先创建测试 Cube

本轮不要加载 GLB。

在 Three.js Scene 中创建一个测试 Cube，用于验证整个交互链路。

Cube：

```text
name = "demo_cube"
```

默认材质：

- 浅灰色
- Roughness 适中
- 不使用高反射材质

背景使用非常浅的灰色或接近白色。

添加基本灯光：

- AmbientLight 或 HemisphereLight
- DirectionalLight

保证模型有自然的明暗关系即可，不要做复杂灯光。

# 七、Raycaster 交互

必须实现 Three.js `Raycaster`。

## Hover

鼠标移动到 Cube：

```text
Cube 临时变为 Hover 颜色
```

鼠标移开：

```text
恢复默认颜色
```

Hover 颜色不要太艳。

---

## Click

点击 Cube：

```text
Cube 进入 Selected 状态
```

表现：

- 保持明显高亮
- 右侧显示 Cube 信息

例如：

```text
名称：测试立方体
ID：demo_cube
简介：用于验证 Web 3D Viewer 的模型点击、选中和信息联动。
```

点击空白区域：

```text
取消 Selected
恢复默认颜色
右侧恢复“未选择模型部件”
```

注意：

```text
Selected 优先级 > Hover
```

也就是说：

对象已经 Selected 时，鼠标 Hover 不应覆盖 Selected 状态。
