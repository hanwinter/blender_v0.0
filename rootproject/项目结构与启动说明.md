## 安装与启动

当前依赖已经安装。首次安装或重建环境，在项目根目录执行：

```powershell
Set-Location 'C:\AllFiles\MyFolderOMEN\project_blender\3d-model-platform'
powershell -ExecutionPolicy Bypass -File .\scripts\setup.ps1
```

两个终端分别启动：

```powershell
Set-Location 'C:\AllFiles\MyFolderOMEN\project_blender\3d-model-platform'
powershell -ExecutionPolicy Bypass -File .\scripts\start-dev.ps1 -Service backend
```

```powershell
Set-Location 'C:\AllFiles\MyFolderOMEN\project_blender\3d-model-platform'
powershell -ExecutionPolicy Bypass -File .\scripts\start-dev.ps1 -Service frontend
```

服务前台运行，Ctrl+C 停止。已运行时不必重复启动；端口占用会明确报错。

也可单独执行：

```powershell
Set-Location 'C:\AllFiles\MyFolderOMEN\project_blender\3d-model-platform\backend'
.\.venv\Scripts\python.exe -m app.run
```

```powershell
Set-Location 'C:\AllFiles\MyFolderOMEN\project_blender\3d-model-platform\frontend'
npm run dev
```

后端依赖使用固定版本，前端通过 package-lock.json 和 npm ci 重复安装。
后端默认开发重载，添加 --no-reload 可关闭。

## 配置与 Debug

根 .env 管理 FRONTEND_PORT、BACKEND_PORT、VITE_API_BASE_URL、VITE_DEFAULT_MODEL、VITE_VIEWER_DEBUG、DATABASE_PATH。
默认值为 5174、8000、/api、demo、false 和 backend/viewer.db。
根、frontend、backend 均有 .env.example；共享端口在根维护。

DATABASE_PATH 相对项目根目录解析。shell 环境优先；组件 .env 优先于根 .env。
前端环境变更后重启 Vite，生产需重新构建。

页面模型下拉框可切换 Cube 和交互测试模型。
开发环境点击模型标题右侧 Debug 图标查看详细信息；也可设置 VITE_VIEWER_DEBUG=true 后重启。
生产默认关闭 Debug 并隐藏开关。

错误按网络、模型不存在、模型加载、元数据加载、无效元数据、ID 不一致和重复 ID 分类。
元数据错误不阻止几何显示或拾取，详细代码与问题只在 Debug 模式显示。

## 验证命令

前后端运行后，在 frontend：

```powershell
npm run build
$env:TEST_BROWSER_CHANNEL = 'chrome'
npm run test:e2e
```

常规有 17 项测试，production.spec.ts 未设置预览 URL 时跳过。
本机 Chrome 不存在时可安装 Playwright Chromium，并取消 TEST_BROWSER_CHANNEL 设置。

生产预览验证：

```powershell
npm run preview -- --port 4187 --strictPort
```

另一个前端终端：

```powershell
$env:TEST_BROWSER_CHANNEL = 'chrome'
$env:PRODUCTION_BASE_URL = 'http://127.0.0.1:4187'
npx playwright test production.spec.ts
```

后端目录：

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
.\.venv\Scripts\python.exe -m pip check
```

第二轮通过 17 项常规浏览器测试、1 项生产测试和 3 项数据库测试。
已验证 1000 次高亮切换保持固定材质数、材质及几何释放次数、挂载/卸载无 RAF 累积、异常元数据仍能选中，以及桌面/窄手机截图。
临时端口启动与 API 代理、端口占用报错和环境覆盖已经验证。

## 当前范围与下一阶段

GLB 来源仅保留类型和 Loader 入口，不执行真实加载；空 URL 不再代表 Cube。
没有人体、上传、CRUD、后台、权限、动画、LOD、VR、WebGPU、Docker 或 Alembic。

本轮后冻结架构。真实模型就绪时新增 GLB Loader 与 ModelPart 映射，按资产补充资源释放；Runtime 和业务信息面板沿用既有契约。
